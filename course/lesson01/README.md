# 第01课 输入输出与程序基础

## 一、程序基础与注释

### 1. 程序基本构成

C 程序由语句构成，代码最终会被翻译成二进制指令，在计算机上执行。

### 2. 注释

注释是写给人看的说明文字，**不参与编译、不影响程序运行**，仅用于标注代码逻辑。

- **单行注释**：以 `//` 开头，仅注释当前行
- **多行注释**：以 `/*` 开头、`*/` 结尾，可跨行注释

示例：

```
#include <stdio.h>

/*
  这是多行注释
  主函数是程序的入口
*/
int main()
{
    // 这是单行注释：向屏幕输出一句话
    printf("Hello World\n");
    return 0;
}
```

## 二、变量与基础数据类型

### 1. 变量概念

变量是存储数据的容器，每个变量对应一种数据类型。
定义格式：

```
数据类型 变量名 = 初始值;
```

### 2. 常用基础数据类型

| 类型 | 说明 |
| --- | --- |
| `int` | 整型，存储整数 |
| `long long` | 长整型，存储更大范围的整数 |
| `float` | 单精度浮点数，存储小数 |
| `double` | 双精度浮点数，精度更高的小数 |
| `char` | 字符型，存储单个字符 |

## 三、格式化输出 printf

### 功能

按照指定格式，向屏幕输出内容。

### 语法

```
printf("格式控制字符串", 变量1, 变量2, ...);
```

### 示例

```
int age = 20;
float money = 6.66;
printf("Larry的年龄是%d,他有%f元", age, money);
```

运行输出结果：

```
Larry的年龄是20,他有6.660000元
```

## 四、格式化输入 scanf

### 功能

从键盘读取用户输入，按照格式存入对应的变量中。

### 语法

```
scanf("格式控制字符串", &变量1, &变量2, ...);
```

> 
> 注意：变量名前必须加 `&`（取地址符）。

### 示例

```
int age;
float money;
scanf("%d %f", &age, &money);
```

键盘输入：`20 6.66`
程序会自动将 `20` 存入 `age`，`6.66` 存入 `money`。

## 五、单个字符输入输出

专门用于处理单个字符的读写：

- `getchar()`：从键盘读取一个字符
- `putchar(字符)`：向屏幕输出一个字符

示例：

```
char c;
c = getchar();   // 读取键盘输入的一个字符
putchar(c);      // 将读取的字符输出到屏幕
```

## 六、格式说明符汇总

| 说明符 | 含义 | 匹配数据类型 |
| --- | --- | --- |
| `%d` | 十进制整数 | `int` |
| `%lld` | 十进制长整数 | `long long` |
| `%c` | 单个字符 | `char` |
| `%s` | 字符串 | 字符数组 |
| `%f` | 浮点数 | `float` / `double` |

## 七、内存存储区域

C 程序运行时，数据会存放在不同的内存区域：

1. **代码区**：存放程序的机器指令
2. **全局/静态存储区**：存放全局变量、静态变量；程序运行全程存在，程序结束才销毁
3. **栈区**：存放局部变量、函数参数；由系统自动分配和释放
4. **堆区**：由程序员通过动态分配函数（`malloc`/`free`、`new`/`delete`）管理的内存区域
5. **常量区**：存放常量字符串等不可修改的数据

## 八、程序编译过程

C 语言从源代码到可执行程序，分为 4 个阶段：

1. **预处理**：`.c` → `.i`
读取源代码，完成宏展开、条件编译、头文件包含等操作
2. **编译**：`.i` → `.s`
将预处理后的代码翻译为汇编语言
3. **汇编**：`.s` → `.o` / `.obj`
将汇编语言转换为机器语言指令（目标文件）
4. **链接**：将多个目标文件、库文件整合，生成最终的可执行程序
